# sparse-to-raw v0.6.0

Стабильный релиз ветки функциональности v0.6.0.

## Основные возможности

- Потоковая конвертация RAW → Android Sparse v1.0 с чанками RAW, FILL и DONT_CARE, CRC32, необязательным SHA-256, отменой и JSON-отчётами.
- Логическое сравнение RAW/Sparse без промежуточного RAW-файла, с поиском первого отличия и SHA-256 логического содержимого.
- Отдельный Sparse Validator: проверка заголовков, структуры чанков, учёта блоков, CRC32 checkpoint, общей контрольной суммы и лишних данных.
- Повторно используемые JSON Batch Profiles для смешанных очередей Sparse → RAW, RAW → Sparse и QFIL.
- Анализ Qualcomm QFIL XML и сборка RAW по физическим разделам. Patch-команды только анализируются и не исполняются.
- Структурированные JSON-отчёты о конвертации, проверке результата, валидации, сравнении, QFIL и пакетных операциях.
- Русский и английский CLI/GUI.

## Windows-загрузки

GitHub Actions собирает и прикладывает к релизу:

- `sparse-to-raw.exe` — автономная CLI.
- `sparse-to-raw-gui.exe` — отдельный исполняемый файл GUI.
- `sparse-to-raw-gui-windows.zip` — GUI-пакет с папкой и библиотеками. Распаковывайте архив целиком, сохраняя структуру каталогов.
- `SHA256SUMS.txt` — SHA-256 для трёх пакетов приложений.

Работоспособность упакованного приложения подтверждена на компьютере с Windows без установленного Python.

## Объём проверки совместимости

Побайтное сравнение с `simg2img.exe` выполнено на двух реальных Android Sparse-образах: `super.img` (около 3,6 ГБ) из заводской прошивки Blackview и `userdata_exp.ai.img` (около 6,83 ГБ) из заводской прошивки Google Pixel. Оба результата совпали. Это ограниченная выборка, а не гарантия поддержки всех vendor-вариантов Sparse и всех форматов прошивок.

Контейнеры Android Dynamic Partitions (`super`) и произвольные многокомпонентные наборы `super_*` не входят в проверенную область поддержки. В [обсуждении 4PDA, сообщения #5464–#5481](https://4pda.to/forum/index.php?showtopic=496786&st=5460) разбирается десятифайловая структура `super` прошивки Vivo V70 Elite и объясняется, почему её нельзя без проверки склеивать через `copy /b` или считать одним самостоятельным Sparse v1. Этот случай не тестировался в `sparse-to-raw`.

## Безопасность и ограничения

- Утилита работает только с файлами. Она не прошивает устройства и не взаимодействует с подключёнными телефонами.
- QFIL patch-команды разбираются и попадают в отчёты, но не исполняются.
- `--merge-parts` предназначен для самостоятельных корректных файлов Sparse v1; это не парсер Dynamic Partitions и не средство реконструкции произвольных разделённых контейнеров.
- Перед использованием результатов в критически важных операциях независимо проверяйте выходные файлы.
