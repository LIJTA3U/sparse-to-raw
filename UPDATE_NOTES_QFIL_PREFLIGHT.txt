sparse-to-raw v0.7.0-dev — QFIL preflight update

Apply this update by extracting the archive contents directly into the root of your existing project folder and allowing the listed files to be replaced.

What changed:
- New CLI command: qfil-validate. It performs the same full planning checks as QFIL RAW assembly without creating the output directory or RAW files.
- Full streaming validation of each referenced Sparse source, including stored CRC checkpoints and the image checksum when present. No expanded RAW temporary file is created.
- Checks raw source lengths and file_sector_offset, LUN sector geometry, sector expressions, overlaps, planned output names, and available disk space.
- QFIL GUI: new Validate package button, per-LUN disk sector field (for example 0=61071360; 1=30535680), background validation worker, and progress bar.
- Updated Russian/English QFIL and CLI documentation and changelogs.
- Added tests for successful preflight, corrupted Sparse CRC, undersized RAW source, end-relative sector expressions, GUI disk-sector parsing, multiple rawprogram manifests/LUNs, and CLI JSON reporting.

After overlaying the files, run from the project root:

  py -m unittest tests.test_qfil_xml -v
  py -m unittest discover -s tests -p "test_*.py" -v
  py tests\gui_smoke_tests.py

The GUI smoke test requires the project's GUI dependencies (PySide6). The current build environment did not have PySide6, so GUI smoke tests were syntax-checked but not executed here.

CLI example:

  py sparse_to_raw.py qfil-validate rawprogram0.xml rawprogram1.xml --patch-xml patch0.xml --search-dir . --output-dir raw-output --disk-sectors 0=61071360

The command validates the package and reports the planned output files. It does not create raw-output or any RAW file.
