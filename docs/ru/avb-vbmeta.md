# AVB / VBMeta Inspector

В `sparse-to-raw` добавлен просмотрщик метаданных Android Verified Boot (AVB), работающий только на чтение. Он принимает самостоятельный `vbmeta.img` или образ раздела с AVB footer. Команда доступна в CLI как `vbmeta-info`, а в GUI — через **«Инструменты» → AVB / VBMeta Inspector**.

## CLI

```powershell
py sparse_to_raw.py vbmeta-info vbmeta.img
py sparse_to_raw.py vbmeta-info system.img --json-report vbmeta-report.json
```

JSON-отчёт содержит заголовок VBMeta и размеры блоков, требуемую версию libavb, алгоритм, rollback index и его расположение, флаги, release string, размерность и отпечатки SHA-1 / SHA-256 публичного ключа, сводку public-key metadata, сведения о footer (если он присутствует) и разобранные descriptors. Поддерживаются типы Property, Hash, Hashtree, Kernel Cmdline и Chain Partition. Неизвестные теги сохраняются в отчёте вместе с номером тега и хешем содержимого.

Для поддерживаемых алгоритмов AVB на основе SHA-256 и SHA-512 инспектор вычисляет встроенный хеш по заголовку VBMeta и auxiliary block и сравнивает его с хешем из authentication block. Отчёт содержит `match`, `mismatch` или соответствующий статус неприменимости/неподдерживаемого алгоритма. Перед чтением блоков парсер проверяет объявленные границы, длины descriptors, отсутствие пересечений областей auth/aux и ограничения размера.

## GUI

Откройте **«Инструменты» → AVB / VBMeta Inspector**, выберите `vbmeta.img` или образ с AVB footer и нажмите **«Прочитать метаданные»**. Таблица descriptors показывает краткую сводку. Выберите строку, чтобы увидеть полный разобранный descriptor в панели сведений. После анализа отчёт доступен через действие сохранения JSON в главном окне.

## Ограничения безопасности

Это просмотрщик метаданных, а не полноценный AVB verifier. Инструмент **не** выполняет следующие действия:

- не проверяет RSA-подпись с использованием встроенного публичного ключа;
- не сравнивает ключ с доверенным ключом, хранилищем доверия загрузчика или заданным пользователем эталоном;
- не сравнивает rollback index со значениями, сохранёнными устройством;
- не прошивает, не патчит, не отключает и не изменяет AVB metadata или разделы устройства.

Совпадение встроенного хеша подтверждает только то, что хеш, записанный в структуре VBMeta, совпадает с заголовком и auxiliary block, прочитанными инспектором. Это не доказывает, что образ подписан доверенным ключом или что устройство примет его. Когда требуется проверка подписи или доверия устройства, используйте независимую процедуру AVB verification.
