# Политика безопасности

Пожалуйста, ответственно сообщайте об уязвимостях, которые могут привести к потере данных, повреждению файлов, небезопасной работе с путями или непреднамеренной перезаписи.

Если для репозитория включена приватная отправка уязвимостей GitHub, воспользуйтесь **Security → Report a vulnerability**. Не публикуйте в открытом Issue чувствительные образы прошивок, приватные ключи, токены или персональные данные. Если приватный канал недоступен, создайте Issue с кратким описанием и попросите безопасный способ передачи минимального примера.

Утилита предназначена для чтения файлов и, при необходимости, записи результатов. Она не подключается к телефону и не прошивает разделы устройства. В сообщении укажите версию приложения, ОС, версию Python (если применимо), команду или действие и очищенный от личных данных текст ошибки.
