## v0.6.0-rc1 — кандидат релиза

Этот кандидат объединяет функциональность ветки v0.6.0 и предназначен для финальной межплатформенной проверки и тестирования Windows-пакетов.

### Конвертация и целостность образов

- Добавлена потоковая конвертация RAW → Android Sparse v1.0 с настройкой размера блока, чанками `RAW` / `FILL` / `DONT_CARE`, CRC32, необязательным SHA-256, атомарной записью, отменой и JSON-отчётами.
- Добавлен отдельный потоковый Sparse Validator: проверка заголовков, структуры и длин чанков, учёта блоков, CRC32 checkpoint, необязательной общей контрольной суммы и лишних данных в конце — без создания RAW-файла.
- Добавлено потоковое логическое сравнение RAW ↔ RAW, RAW ↔ Sparse и Sparse ↔ Sparse с поиском первого отличающегося байта и расчётом SHA-256 логического содержимого — без промежуточного RAW.
- Сохранены Sparse → RAW, проверка записанного RAW повторным чтением, анализ образов и объединение частей в заданном порядке.

### QFIL и пакетная обработка

- Добавлены анализ Qualcomm QFIL `rawprogram*.xml` / `patch*.xml` и сборка RAW по физическим разделам. Patch-инструкции анализируются и попадают в отчёт, но не исполняются.
- Добавлена смешанная последовательная Batch Queue для Sparse → RAW, RAW → Sparse и QFIL.
- Добавлены версионированные JSON-профили пакетной очереди: порядок заданий, настройки операций, относительные пути, когда это возможно, проверка схемы, защита от перезаписи и безопасная замена очереди.
- Добавлены JSON-отчёты для конвертации, проверки, сравнения, QFIL и пакетных запусков.

### GUI и подготовка релиза

- Добавлены отдельные GUI-инструменты RAW → Sparse, логического сравнения и Sparse Validator с прогрессом и отменой там, где она поддерживается.
- Версия CLI и GUI централизована в одном месте.
- Добавлен Windows release workflow для отдельного CLI EXE, GUI-пакета с папкой ресурсов и автономного GUI EXE. Перед публикацией workflow запускает тесты, компиляцию, проверки упакованного CLI и самопроверку упакованного GUI, затем прикладывает SHA-256 манифест к пакетам.
- CI проверяет Python 3.10–3.14 на Windows и Linux; GUI smoke tests запускаются с PySide6 на Windows и Linux.

### Совместимость и ограничения безопасности

- CLI использует только стандартную библиотеку Python; для GUI при запуске из исходников требуется PySide6.
- Программа работает с файлами образов и не прошивает устройства, не взаимодействует с подключёнными телефонами.
- Patch-команды QFIL только анализируются и отображаются в отчётах — они не исполняются.
- Перед критически важным использованием независимо проверяйте полученные файлы.

### Проверки кандидата релиза

- Основные модульные тесты: 125 успешно пройдены в среде подготовки.
- Компиляция Python и CLI `--version` / `--help`: успешно.
- GUI smoke tests Windows были запущены сопровождающим проекта на предыдущей сборке dev12; для RC необходима проверка GitHub Actions и тест на чистой Windows-системе до объявления стабильного v0.6.0.
- Windows EXE собираются через `.github/workflows/build-windows-release.yml`; в этот архив исходников они не включены.

## v0.6.0-dev10 — Sparse Validator

- Добавлен отдельный потоковый Sparse Validator в CLI и GUI.
- Проверяются заголовки, типы и размеры чанков, учёт блоков, границы файла, CRC32 checkpoints и необязательная общая контрольная сумма — без создания RAW-файла.
- Формируется структурированный отчёт с оценкой целостности, составом чанков, предупреждениями, необязательным SHA-256 логического содержимого и экспортом JSON.
- В GUI добавлены прогресс, отмена и отдельное окно проверки.

## v0.6.0-dev9 — логическое сравнение RAW/Sparse

- Добавлено потоковое логическое сравнение RAW ↔ RAW, RAW ↔ Sparse и Sparse ↔ Sparse.
- Во время чтения Sparse проверяется структура, контрольные точки CRC32 чанков и заданная общая контрольная сумма; промежуточный раскрытый RAW-файл не создаётся.
- Отчёт содержит SHA-256 обоих логических содержимых, их размеры, форматы и смещение первого отличающегося байта.
- Добавлена CLI-подкоманда `compare` и фоновый GUI-диалог сравнения с прогрессом, отменой и экспортом JSON.
- Добавлены регрессионные тесты совпадающих образов, различий, разных размеров, повреждённых контрольных сумм, отмены и кодов завершения CLI.
