## v0.6.0-dev4

- Добавлены смешанные последовательные задания Sparse и QFIL в Batch Queue.
- Для QFIL XML добавлена отдельная тематическая иконка на главной панели и в действиях очереди.
- Элементы QFIL в очереди хранят пути rawprogram/patch, папку поиска, папку результата и политику пересечений.

## v0.6.0-dev3 — интеграция QFIL в GUI

- Добавлено отдельное окно QFIL XML на основной панели и в окне Batch Queue.
- Реализован GUI-сценарий выбора rawprogram/patch-манифестов, папки поиска прошивки, анализа разделов и предупреждений, а также сборки RAW по LUN.
- Patch-команды только анализируются: приложение не выполняет их и не прошивает устройства.
- Обработка QFIL пока является отдельным сценарием и ещё не представлена типом задания в очереди конвертации Sparse.

## [Unreleased] — разработка v0.6.0

### Изменено
- Версия сборки разработки обновлена до `v0.6.0-dev2` после добавления двуязычной локализации CLI.


### Добавлено
- Локализация CLI: английский по умолчанию, выбор `--lang en|ru` для команды и переменная `SPARSE_TO_RAW_LANG` для сеанса; справка, сводки и основные ошибки Sparse/QFIL учитывают выбранный язык.
- Анализ манифестов Qualcomm QFIL `rawprogram*.xml` и `patch*.xml`, включая сводку по LUN/разделам, поиск исходных файлов и JSON-отчёты.
- Потоковая сборка RAW по физическим партициям: поддержка `program`/`erase`, `file_sector_offset`, `SECTOR_SIZE_IN_BYTES`, Sparse-источников и выражений `NUM_DISK_SECTORS-N`.
- Защита от неоднозначных источников, пересекающихся диапазонов, XML DTD/entity, нехватки дискового места и случайной перезаписи. Patch XML анализируется, но не применяется.
- Увеличенная векторная пиктограмма зоны перетаскивания и более структурированный CLI.
- Отдельные тесты QFIL XML, поиска файлов, сборки RAW, ошибок и CLI.


## [0.5.0] — 2026-11-02

### Добавлено
- Локализация CLI: английский по умолчанию, выбор `--lang en|ru` для команды и переменная `SPARSE_TO_RAW_LANG` для сеанса; справка, сводки и основные ошибки Sparse/QFIL учитывают выбранный язык.
- Постраничный просмотр структуры Sparse с полной проверкой перед просмотром, смещениями/размерами/контрольными суммами чанков, фильтрами по типу, поиском и потоковым экспортом CSV/JSON.
- Фоновый отменяемый экспорт структуры с атомарной публикацией и обнаружением изменения исходного файла.
- Идентификатор Windows taskbar и установка собственной иконки для запущенного GUI.
- Локализация сообщений журнала операций и категорий диагностики для русского/английского режимов.
- Сглаженная угловатая рамка с более плавными переходами слева при сохранении существующего тёмного дизайна с бирюзовыми и жёлтыми акцентами.
- Улучшенное управление пакетной очередью: перестановка перетаскиванием, отмена/пропуск отдельных задач, пауза и продолжение между файлами, повтор выбранных ошибок и фильтры статусов.
- Общий прогресс и JSON-сводка очереди учитывают ожидание, выполнение, успех, ошибки, отмену и пропуск.
- Локальная ротируемая история диагностики в формате JSONL с фильтрами по уровню, операции и периоду, а также текстовым поиском.
- Экспорт диагностического ZIP с версиями среды и маскированием путей пользовательского профиля и значений, похожих на секреты.
- Метрики завершённых операций конвертации, анализа, объединения и пакетной обработки: длительность, обработанный/выходной объём, число чанков и средняя скорость, если доступны.
- Поиск независимых групп Sparse-частей в GUI с числовой сортировкой и проверкой пропусков, дубликатов индексов, заголовков и размеров блоков.
- Общие предварительные проверки выходных путей, прав записи, свободного места, временного пространства для объединения и конфликтов имён в очереди.
- Необязательная проверка RAW повторным чтением: сверка размера и SHA-256 временного результата с ожидаемым логическим содержимым до атомарного сохранения.
- Параметр CLI `--verify-output` для конвертации и `--merge-parts`; сведения о проверке входят в JSON-отчёт.
- Сохраняемая настройка проверки RAW в одиночной конвертации, пакетной очереди и объединении Sparse.

### Изменено
- Существующая компоновка и цветовая палитра GUI сохранены; рамка рисуется сглаженными QPainterPath вместо пиксельной маски области.
- Прогресс проверки результата показывается отдельным этапом чтения; при ошибке или отмене существующий выходной файл сохраняется.

## [0.2.0] — выпущена

### Добавлено
- Локализация CLI: английский по умолчанию, выбор `--lang en|ru` для команды и переменная `SPARSE_TO_RAW_LANG` для сеанса; справка, сводки и основные ошибки Sparse/QFIL учитывают выбранный язык.
- Режим `--info` для метаданных и проверки без создания RAW.
- Режим `--verify-only` для отдельной проверки структуры и контрольных сумм.
- Защита от случайной перезаписи; `--force` разрешает явную замену.
- Индикатор прогресса, скорость обработки и количество обработанных байтов.
- SHA-256 логического RAW-содержимого через `--sha256`.
- JSON-отчёты через `--json-report`.
- Объединение независимых Sparse-файлов в заданном порядке через `--merge-parts`.
- GitHub Actions для основных тестов в Windows и Linux.
- Локализованный README, бейджи, руководство контрибьютора и шаблоны Issues.
