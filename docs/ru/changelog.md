# История изменений

Проект следует формату [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased] — разработка v0.5.0

### Добавлено
- Поиск независимых групп Sparse-частей в GUI с числовой сортировкой и проверкой пропусков, дубликатов индексов, заголовков и размеров блоков.
- Общие предварительные проверки выходных путей, прав записи, свободного места, временного пространства для объединения и конфликтов имён в очереди.
- Необязательная проверка RAW повторным чтением: сверка размера и SHA-256 временного результата с ожидаемым логическим содержимым до атомарного сохранения.
- Параметр CLI `--verify-output` для конвертации и `--merge-parts`; сведения о проверке входят в JSON-отчёт.
- Сохраняемая настройка проверки RAW в одиночной конвертации, пакетной очереди и объединении Sparse.

### Изменено
- Прогресс проверки результата показывается отдельным этапом чтения; при ошибке или отмене существующий выходной файл сохраняется.

## [0.4.0] — выпущена

### Добавлено
- Переключение языка GUI между русским и английским с сохранением выбора.
- Отображение скорости в МБ/с, МиБ/с и Мбит/с.
- Иконка приложения и увеличенные иконки действий.
- Сохранение геометрии окна, путей, настроек и истории последних файлов.
- Анализ Sparse-образа с экспортом JSON без создания RAW.
- Последовательная очередь пакетной конвертации с отменой и итоговым JSON-отчётом.
- Визуальное объединение независимых Sparse-частей с ручным изменением порядка.
- Подробные отчёты о конвертации и объединении.
- Callback-и прогресса, событий и отмены при объединении Sparse-частей.
- Тесты монотонности прогресса и безопасной отмены объединения.

### Изменено
- GUI расширен без замены существующего CLI и основной реализации конвертера.
- Windows-пакеты включают иконку приложения и GUI-ресурс.

## [0.3.0] — выпущена

### Добавлено
- Экспериментальный настольный GUI на PySide6 с безрамочным геометрическим окном.
- Прогресс по обработанным байтам и чанкам, журнал операций и SHA-256.
- Фоновый рабочий поток и безопасная отмена с удалением временного файла.
- Windows ZIP-пакет приложения и отдельный однофайловый GUI EXE.
- GUI smoke-тесты в Windows и Linux.

### Изменено
- Конвертер предоставляет необязательные callback-и прогресса, событий и отмены; CLI сохраняет прежнее поведение по умолчанию.

## [0.2.0] — выпущена

### Добавлено
- Режим `--info` для метаданных и проверки без создания RAW.
- Режим `--verify-only` для отдельной проверки структуры и контрольных сумм.
- Защита от случайной перезаписи; `--force` разрешает явную замену.
- Индикатор прогресса, скорость обработки и количество обработанных байтов.
- SHA-256 логического RAW-содержимого через `--sha256`.
- JSON-отчёты через `--json-report`.
- Объединение независимых Sparse-файлов в заданном порядке через `--merge-parts`.
- GitHub Actions для основных тестов в Windows и Linux.
- Локализованный README, бейджи, руководство контрибьютора и шаблоны Issues.
