# Установка

## Windows-релиз (рекомендуется для обычных пользователей)

1. Откройте [GitHub Release v0.4.0](https://github.com/LIJTA3U/sparse-to-raw/releases/tag/v0.4.0).
2. Скачайте `sparse-to-raw-gui-windows.zip`.
3. Полностью распакуйте архив в выбранную папку.
4. Запустите `sparse-to-raw-gui.exe` из распакованной папки приложения.

Сохраняйте структуру распакованной папки. ZIP содержит EXE, библиотеки и ресурсы, необходимые GUI. Отдельно устанавливать Python и PySide6 не требуется.

В релиз также входят однофайловая GUI-сборка `sparse-to-raw-gui.exe` и консольная утилита `sparse-to-raw.exe`.

## Запуск CLI из исходников

Требуется Python 3.10 или новее. CLI использует только стандартную библиотеку Python.

```powershell
py --version
py sparse_to_raw.py --help
```

Устанавливать пакеты через `pip` для CLI не нужно.

## Запуск GUI из исходников

Установите Python 3.10 или новее, откройте терминал в каталоге проекта и выполните:

```powershell
py -m pip install -r requirements-gui.txt
py sparse_to_raw_gui.py
```

Для GUI требуется PySide6. Консольная версия по-прежнему не зависит от PySide6.

## Самостоятельная сборка приложения

Для упаковки через PyInstaller установите зависимости сборки:

```powershell
py -m pip install -r requirements-build.txt
```

Точные команды приведены в разделе [Разработка и сборка](development.md).

## Свободное место

Раскрытый RAW-образ может быть значительно больше исходного Sparse-файла. Перед конвертацией проверьте ожидаемый RAW-размер и свободное место на целевом диске. Объединение нескольких частей также использует временные файлы; подробности — в [руководстве GUI](gui-guide.md) и [руководстве CLI](cli-guide.md).
