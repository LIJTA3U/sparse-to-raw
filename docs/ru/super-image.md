# Android Super Image: просмотр и извлечение

Модуль **Super Image** позволяет читать метаданные Android Dynamic Partitions из `super.img` и извлекать логические разделы в отдельные RAW-файлы.

Поддерживается входной файл в формате RAW или Android Sparse. Для Sparse-образа программа автоматически создаёт временную RAW-копию, необходимую для чтения LP-метаданных; исходный файл не изменяется. После операции временный файл удаляется.

## Возможности и ограничения

- Чтение геометрии LP и основных/резервных копий метаданных.
- Проверка SHA-256 контрольных сумм геометрии, заголовка и таблиц.
- Просмотр логических разделов, размеров, групп, количества extents и атрибутов.
- Выбор слота метаданных.
- Извлечение одного, нескольких или всех разделов в отдельные файлы `NAME.img`.
- Потоковое копирование с ограниченным использованием оперативной памяти, прогрессом и отменой. Каждый раздел фиксируется отдельным атомарным действием: уже завершённые файлы сохраняются, если последующий раздел отменён или завершился ошибкой.
- Существующие файлы не перезаписываются без явного подтверждения/параметра `--force`.

Текущая реализация поддерживает версии LP metadata 10.0–10.2. Для извлечения линейные extents должны ссылаться на block device с индексом `0`, то есть на один входной файл `super`. Конфигурации retrofit, в которых данные разделов распределены по нескольким физическим образам, пока не поддерживаются. Неизвестные или повреждённые метаданные отклоняются.

Модуль работает только с файлами: он не подключается к телефону, не разблокирует загрузчик и не прошивает разделы. Результаты следует независимо проверять перед использованием в критически важных операциях.

## Графический интерфейс

Откройте **«Super-образ»** в верхней панели. Выберите RAW- или Sparse-файл `super.img`, номер слота и нажмите **«Прочитать структуру»**. После загрузки таблицы отметьте необходимые разделы, укажите каталог назначения и нажмите **«Извлечь выбранные»**. По умолчанию отмечены все обнаруженные разделы.

Если источник или номер слота изменён после чтения метаданных, список сбрасывается и перед извлечением требуется повторный анализ. Если выходные файлы уже существуют, программа запрашивает подтверждение их замены.

## CLI

Посмотреть метаданные без извлечения:

```powershell
py sparse_to_raw.py super-info super.img --slot 0
```

Сохранить результат анализа в JSON:

```powershell
py sparse_to_raw.py super-info super.img --slot 0 --json-report super-info.json
```

Извлечь все разделы:

```powershell
py sparse_to_raw.py super-extract super.img --output-dir extracted
```

Извлечь только выбранные разделы:

```powershell
py sparse_to_raw.py super-extract super.img --output-dir extracted --partition system --partition vendor
```

Для замены уже существующих файлов добавьте `--force`. Параметр `--partition` можно повторять; без него извлекаются все разделы выбранного слота. `--slot` по умолчанию равен `0`.
