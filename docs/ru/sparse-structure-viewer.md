# Просмотр структуры Sparse

Просмотр структуры Sparse показывает чанки Android Sparse Image постранично. Окно открывается кнопкой **«Структура Sparse»** на главной панели.

## Проверка перед просмотром

Нажмите **«Проверить и загрузить»**, чтобы сначала выполнить полную штатную проверку Sparse-файла. Проверяются заголовок, структура чанков, полезные данные, контрольные точки CRC32 и общая контрольная сумма образа, если она указана. Строки не помечаются как проверенные до успешного завершения полной проверки.

После проверки программа повторно читает заголовки чанков для заполнения страниц. Весь файл и вся таблица чанков не загружаются в оперативную память. Размер страницы по умолчанию — 200 строк. Смена фильтра типа, поискового запроса или страницы запускает ограниченное сканирование метаданных.

Размер, время изменения и идентификатор исходного файла проверяются между полной проверкой, чтением страниц и экспортом. Если исходный файл изменился, сохранённый результат проверки сбрасывается, и файл необходимо проверить заново.

## Столбцы таблицы

- **№** — отображаемый порядковый номер чанка, начиная с единицы.
- **Тип** — `RAW`, `FILL`, `DONT_CARE` или `CRC32`.
- **Смещение файла** — позиция заголовка чанка в Sparse-файле.
- **Смещение RAW** — логическое смещение данных в выходном RAW.
- **Блоки** — число выходных блоков, представленных чанком (контрольные точки CRC32 не содержат выходных блоков).
- **В файле** — полный размер чанка в Sparse-файле, включая заголовок.
- **После распаковки** — количество логических байтов RAW, представленных чанком.
- **Контрольная сумма** — сохранённое значение CRC32 для чанков-контрольных точек, если оно есть.
- **Проверка** — показывает, что предыдущая полная проверка завершилась успешно; строки CRC32 отмечаются отдельно.

Выберите строку, чтобы посмотреть дополнительные смещения, размер полезных данных, число блоков, контрольную сумму и шаблон FILL.

## Поиск и фильтры

Выберите один тип чанка или все типы. Поиск выполняется по отображаемому индексу, коду типа, смещениям в файле и RAW, количеству блоков, сохранённому/распакованному размеру, контрольной сумме и шаблону FILL. Результаты отображаются страницами; переходы вперёд и назад не сохраняют всю таблицу в памяти.

## Экспорт

После успешной полной проверки можно экспортировать всю структуру в CSV или JSON. Экспорт выполняется в фоновом потоке, показывает прогресс и может быть отменён. Данные записываются во временный файл по одной записи чанка, после чего готовый файл атомарно публикуется. Существующий файл не заменяется без явного подтверждения. Экспорт содержит только метаданные и структуру чанков — полезные данные RAW не копируются.

Описание формата и параметров CLI см. в [руководстве CLI](cli-guide.md).
