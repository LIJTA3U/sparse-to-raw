# Security policy

Please report vulnerabilities that may cause data loss, file corruption, unsafe path handling, or unintended file replacement responsibly.

If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Do not publish sensitive firmware images, private keys, access tokens, or personal data in a public issue. If private reporting is unavailable, open an issue with a minimal description and ask for a safe way to share a reproducer.

The utility is designed to read files and optionally write output files. It does not connect to a phone or flash device partitions. Include the application version, operating system, Python version (if relevant), command or action, and a sanitized error message in a report.
