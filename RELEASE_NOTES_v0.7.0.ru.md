# sparse-to-raw v0.7.0

Стабильный релиз функциональной ветки v0.7.0.

В версии 0.7.0 `sparse-to-raw` расширяется от конвертера Sparse-образов до набора инструментов для анализа образов прошивок Android. При этом сохраняются CLI на стандартной библиотеке Python без дополнительных зависимостей и графический интерфейс PySide6.

## Основные возможности

### Super Image Inspector и извлечение логических разделов

- Анализ метаданных Android Dynamic Partitions в RAW- и Android Sparse-образах `super.img`.
- Проверка LP geometry и контрольных сумм метаданных, чтение основной копии метаданных и переход к резервной при необходимости.
- Просмотр логических разделов, групп, слотов и extents; извлечение выбранных логических разделов.
- CLI-команды `super-info` и `super-extract`, а также отдельный инструмент в GUI.

### Предварительная проверка пакетов Qualcomm QFIL

- Команда `qfil-validate` анализирует QFIL-пакет без создания выходных RAW-образов.
- Проверяются ссылки на исходные файлы, диапазоны RAW, структура Sparse и CRC, секторные диапазоны, пересечения, планируемые выходные файлы для каждого LUN, конфликты имён и свободное место на диске.
- Аналогичная проверка доступна в GUI перед сборкой RAW. Инструкции Patch разбираются и отображаются в отчётах, но не исполняются.

### AVB / VBMeta Inspector

- Анализ самостоятельных VBMeta и образов с AVB footer.
- Просмотр флагов заголовка, rollback metadata, отпечатков публичных ключей и поддерживаемых дескрипторов Property, Hash, Hashtree, Kernel Cmdline и Chain Partition.
- Сравнение встроенных SHA-256 / SHA-512 digest для поддерживаемых алгоритмов.
- CLI-команда `vbmeta-info` и инструмент в меню «Инструменты» GUI.

### Android Boot Image Inspector

- Анализ legacy boot header v0–v2, generic boot header v3–v4 и `vendor_boot` v3–v4.
- Отображение размеров и смещений компонентов, полей ОС и сборки, подсказок о формате Kernel/Ramdisk, DTB, recovery DTBO, фрагментов vendor ramdisk, bootconfig и структурных диапазонов AVB footer/VBMeta.
- CLI-команда `boot-info` и инструмент в меню «Инструменты» GUI.

### Android Ramdisk Inspector

- Инвентаризация CPIO-записей в `boot`, `init_boot`, `recovery`, фрагментах `vendor_boot` и отдельных ramdisk-архивах.
- Поддержка CPIO `newc` / `crc`, проверки CRC, последовательных архивов и встроенной распаковки gzip, bzip2, XZ, LZMA-alone и LZ4 frame / legacy.
- Поиск путей, фильтрация категорий записей, просмотр текста и HEX, отображение UID/GID, экспорт JSON и безопасное извлечение выбранных путей или всего архива.
- Построчное сравнение двух текстовых конфигурационных файлов в GUI с подсветкой добавленных, удалённых и изменённых строк.
- CLI-команды `ramdisk-info`, `ramdisk-extract` и инструмент в меню «Инструменты» GUI.

### GUI и сборка релизов

- Компактная главная панель инструментов; редко используемые инструменты сгруппированы в меню «Инструменты».
- Длительные операции анализа и извлечения выполняются в фоновых потоках с отображением прогресса и отменой там, где она поддерживается.
- GitHub Actions собирает автономный Windows CLI, GUI в одном EXE и GUI-пакет с папкой зависимостей, а также формирует манифест SHA-256.

## Загрузки для Windows

В GitHub Release доступны:

- `sparse-to-raw.exe` — автономная консольная утилита.
- `sparse-to-raw-gui.exe` — автономный GUI в одном EXE.
- `sparse-to-raw-gui-windows.zip` — GUI-пакет с папкой приложения. Распакуйте архив целиком и сохраняйте структуру каталогов.
- `SHA256SUMS.txt` — контрольные суммы SHA-256 трёх пакетов приложения.

Для запуска готовых Windows-приложений не требуется отдельно устанавливать Python или PySide6. Для обычного использования GUI рекомендуется ZIP-пакет с папкой приложения.

## Объём проверки совместимости

- Результат Sparse → RAW побайтно сравнивался с AOSP `simg2img.exe` на двух реальных заводских образах: `super.img` Blackview и `userdata_exp.ai.img` Google Pixel. В обоих случаях содержимое совпало.
- Анализ и извлечение Super Image проверялись на RAW- и заводском Sparse-образах `super.img` Blackview через CLI и GUI; SHA-256 извлечённых разделов в обоих интерфейсах совпали.
- Синтетическая Super Image-фикстура проверяет логические разделы с физически разнесёнными extents.
- Эти проверки охватывают конкретные входные данные и сценарии, но не являются полной сертификацией всех генераторов Sparse, устройств Android, прошивок и конфигураций Dynamic Partitions.

## Известные ограничения

- Поддерживаются версии LP metadata 10.0–10.2. Для извлечения linear extents должны ссылаться на block device с индексом `0`; многобразные retrofit-конфигурации и произвольные наборы `super_*` не поддерживаются.
- VBMeta Inspector проверяет поддерживаемые встроенные digest и разбирает метаданные, но не проверяет RSA-подписи, подлинность доверенного ключа и rollback state устройства.
- Boot Image Inspector работает только на чтение. Он не распаковывает kernel или ramdisk и не проверяет AVB-подписи.
- Ramdisk Inspector поддерживает CPIO `newc` / `crc`. Сигнатуры Zstandard и LZO/lzop распознаются, но потоки не распаковываются в сборке без дополнительных зависимостей. Символические ссылки и специальные записи device/socket/FIFO попадают в манифесты, но не создаются; владельцы, временные метки, права каталогов, SELinux labels и capabilities не восстанавливаются.
- Сравнение конфигураций Ramdisk ограничено текстовыми файлами размером до 256 КиБ каждый; бинарные и усечённые данные отклоняются.
- Инструкции QFIL Patch анализируются и отображаются, но не исполняются.
- Приложение работает только с файлами. Оно не прошивает устройства и не взаимодействует с подключёнными телефонами.

Перед использованием в критически важных сценариях с прошивками самостоятельно проверяйте выходные образы.
