sparse-to-raw v0.7.0-dev — AVB / VBMeta Inspector update

Apply
-----
1. Close sparse-to-raw if it is open.
2. Extract this ZIP directly into the root of your existing project folder.
   Example: C:\Users\<you>\Desktop\sparse_to_raw
3. Allow the files in the archive to replace the older project files.
4. Do not extract the archive into a new nested folder.

What is included
----------------
- New read-only avb_inspector.py module.
- CLI command: vbmeta-info [IMAGE] [--json-report FILE].
- AVB / VBMeta Inspector under GUI -> Tools.
- Parsing for standalone AVB0 VBMeta and images with an AVBf footer.
- Header, rollback index, flags, release string, public-key fingerprints,
  and Property / Hash / Hashtree / Kernel Cmdline / Chain Partition descriptors.
- Embedded SHA-256 / SHA-512 digest comparison for supported algorithms.
- Bounds, descriptor-length, overlap, and block-size safety checks.
- English/Russian documentation and regression tests.
- Windows build workflow explicitly includes avb_inspector and smoke-tests
  the packaged CLI command in English and Russian.
- The update also carries forward the currently integrated QFIL preflight
  changes and the two LP Geometry fallback regression tests.

Run tests (PowerShell, from project root)
-----------------------------------------
py -m unittest tests.test_avb_inspector -v
py -m unittest discover -s tests -p "test_*.py" -v
py -m py_compile *.py tests/*.py

GUI smoke tests (requires requirements-gui.txt / PySide6)
---------------------------------------------------------
$env:QT_QPA_PLATFORM = "offscreen"
py tests\gui_smoke_tests.py

CLI examples
------------
py sparse_to_raw.py vbmeta-info "C:\path\to\vbmeta.img"
py sparse_to_raw.py vbmeta-info "C:\path\to\system.img" --json-report vbmeta-report.json
py sparse_to_raw.py --lang ru vbmeta-info --help

Safety limitations
------------------
This is a metadata inspector, not a complete AVB verifier. It checks the
embedded VBMeta digest when the algorithm is supported, but does NOT verify
the RSA signature, compare the embedded key to a trusted key, or compare the
rollback index with rollback state stored on a device. It never flashes or
modifies an image.
