# sparse-to-raw v0.6.0-rc1

Этот кандидат релиза объединяет функциональность ветки v0.6.0 и предназначен для финального тестирования.

## Основные возможности

- Потоковая конвертация RAW → Android Sparse v1.0 с чанками RAW, FILL и DONT_CARE, CRC32, необязательным SHA-256, отменой и JSON-отчётами.
- Логическое сравнение RAW/Sparse без создания промежуточных RAW-файлов, с поиском первого отличия и SHA-256 логического содержимого.
- Отдельный Sparse Validator: проверка заголовков, размеров чанков, учёта блоков, CRC32 checkpoint, общей контрольной суммы и лишних данных.
- Повторно используемые JSON Batch Profiles для смешанных очередей Sparse → RAW, RAW → Sparse и QFIL.
- Анализ Qualcomm QFIL XML и сборка RAW по физическим разделам. Patch-команды только анализируются и не исполняются.
- Структурированные JSON-отчёты о конвертации, проверке результата, валидации, сравнении, QFIL и пакетных операциях.
- Английский и русский языки CLI и GUI.

## Windows-загрузки

Windows release workflow собирает и прикладывает к GitHub Release:

- `sparse-to-raw.exe` — автономная CLI.
- `sparse-to-raw-gui.exe` — автономная GUI.
- `sparse-to-raw-gui-windows.zip` — GUI-пакет с папкой и необходимыми библиотеками.
- `SHA256SUMS.txt` — SHA-256 для трёх пакетов приложений.

GUI ZIP необходимо распаковать целиком. CLI и GUI EXE собираются и проверяются через GitHub Actions на Windows; в архив исходников исполняемые файлы не входят.

## Важные примечания

- Для запуска из исходников требуется Python 3.10 или новее. CLI использует только стандартную библиотеку Python; для GUI требуется PySide6.
- Утилита обрабатывает только файлы. Она не прошивает устройства и не взаимодействует с подключёнными телефонами.
- QFIL patch-команды разбираются и отображаются в отчётах, но не исполняются.
- Это кандидат релиза. Просьба сообщать об обнаруженных регрессиях до выпуска стабильного v0.6.0.
