# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.2.0] — в разработке

### Добавлено
- Режим `--info` для вывода метаданных и проверки без создания RAW-файла.
- Режим `--verify-only` для отдельной проверки структуры и контрольных сумм.
- Защита от случайной перезаписи выходного файла; флаг `--force` включает явную замену.
- Индикатор прогресса, скорость обработки и обработанный объём.
- Вычисление логического SHA-256 через `--sha256`.
- JSON-отчёт через `--json-report`.
- Объединение независимых Sparse-частей через `--merge-parts` с ручным указанием порядка.
- GitHub Actions для тестов в Windows и Linux.
- Русский README по умолчанию, английская версия в `README.en.md`, бейджи, руководство для контрибьюторов и шаблоны Issues.

### Изменено
- CLI описания и документация приведены к единому набору параметров.
