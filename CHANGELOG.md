# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.4.0] — в разработке

### Добавлено
- Переключение языка GUI между русским и английским с сохранением выбора.
- Переключение отображения скорости между МБ/с, МиБ/с и Мбит/с.
- Иконка приложения и увеличенные иконки действий.
- Сохранение настроек окна, путей и списка последних файлов.
- Диалог анализа Sparse-образа с экспортом JSON-отчёта.
- Очередь пакетной конвертации с последовательной обработкой, отменой и итоговым JSON-отчётом.
- Визуальное объединение независимых Sparse-частей с изменением их порядка.
- Сохранение подробных отчётов для конвертации и объединения.
- Callback-и прогресса, событий и отмены для объединения Sparse-частей.
- Дополнительные тесты монотонности прогресса и безопасной отмены объединения.

### Изменено
- GUI расширен дополнительными инструментами; CLI и формат его параметров сохранены.
- Windows-сборки включают иконку приложения и её ресурс для окна.

## [0.3.0] — выпущена

### Добавлено
- Экспериментальный настольный GUI на PySide6 с безрамочным геометрическим окном.
- Реальный прогресс по байтам и завершённым чанкам, журнал этапов проверки и SHA-256.
- Фоновый рабочий поток и безопасная отмена через удаление временного файла.
- Сборка Windows: ZIP-пакет приложения и отдельный однофайловый GUI EXE.
- GUI smoke-tests на Windows и Linux.

### Изменено
- Конвертер предоставляет необязательные callback-и прогресса, событий и безопасной отмены; CLI по умолчанию работает как прежде.

## [0.2.0] — выпущена

### Добавлено
- Режим `--info` для вывода метаданных и проверки без создания RAW-файла.
- Режим `--verify-only` для отдельной проверки структуры и контрольных сумм.
- Защита от случайной перезаписи выходного файла; флаг `--force` включает явную замену.
- Индикатор прогресса, скорость обработки и обработанный объём.
- Вычисление логического SHA-256 через `--sha256`.
- JSON-отчёт через `--json-report`.
- Объединение независимых Sparse-частей через `--merge-parts` с ручным указанием порядка.
- GitHub Actions для тестов в Windows и Linux.
- Русский README по умолчанию, английская версия в `README.en.md`, бейджи, руководство для контрибьюторов и шаблоны Issues.

### Изменено
- CLI описания и документация приведены к единому набору параметров.
