# Участие в разработке

Спасибо за интерес к проекту! Небольшие исправления, новые тесты и сообщения об ошибках приветствуются.

## Перед созданием Issue

- Проверьте, воспроизводится ли проблема на последней версии проекта.
- Укажите версию Python, ОС и команду запуска.
- Приложите полный текст ошибки и минимальный воспроизводимый пример.
- Не публикуйте прошивки с персональными данными, приватные ключи, токены или образы, распространение которых ограничено.

## Перед Pull Request

1. Создайте отдельную ветку для изменения.
2. Добавьте тесты для новой логики и ошибок.
3. Запустите проверку:

   ```bash
   python -m unittest discover -s tests -v
   ```

4. Обновите `README.md` и `README.ru.md`, если меняются пользовательские параметры или поведение.
5. Обновите `CHANGELOG.md`.
6. Держите реализацию без сторонних зависимостей, если они не обоснованы необходимостью.

## Принципы проекта

- Ошибки формата должны приводить к понятному сообщению и ненулевому коду завершения.
- Ошибка конвертации не должна повреждать существующий выходной файл.
- Изменения должны обрабатываться потоково и не загружать весь образ в память.
- Не добавляйте автоматическую запись в устройство: проект предназначен для работы с файлами.
